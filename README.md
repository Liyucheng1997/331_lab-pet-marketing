# PetOps Italia · 宠物电商工作台

当前版本：**1.2.0**。变更与已知限制见 [CHANGELOG.md](CHANGELOG.md)。仓库不包含商品数据库、商品图片、任务日志或 Codex 登录信息。

1.2 界面改进：主区域顶部以 1–5 切换流程；左侧任务列表支持收起与展开，也可查看历史任务。制作进度根据任务目录中的九宫格、高清成品和验收结果计算阶段百分比，不代表图像模型内部生成百分比。调研和局部修改未产出结果前使用不定进度条。页面每 4 秒更新任务信息，并保留正在编辑的表单内容。调研、排期和上架页使用紧凑摘要栏；制作日历支持日、周、月切换、日期跳转和回到今天，默认周视角。

面向意大利 B2C 的本机工作系统。Python + SQLite + 原生 HTML/CSS/JavaScript，无需 npm 安装。服务仅监听 `127.0.0.1:3310`，不开放公网或局域网。

## 启动

双击 **启动系统.cmd**，浏览器打开 `http://127.0.0.1:3310`。首次运行需要 Python 3.11+；本机已检测到 Python、Codex、Pillow、九宫格技能和 Real-ESRGAN。

也可以在项目目录执行 `python server.py`，保持进程运行。

在另一台 Windows 电脑上使用：先安装 Python 3.11+、Node.js 22+（仅测试需要）、Codex CLI，执行 `python -m pip install -r requirements.txt`，再通过 `codex login` 登录 ChatGPT。另行安装你的九宫格技能与 Real-ESRGAN；这些本机工具不在本仓库内。工具路径可以通过 `PETOPS_LISTING_SKILL`、`PETOPS_FINALIZER`、`PETOPS_REALESRGAN` 环境变量指定。未经安装的功能会在连接与设置中显示缺失。

### EAN 查不到时

先检查条码校验提示。校验通过仅表示数字结构正确，不代表 GS1 注册或网页收录。新版检索会先跨站识别商品，再用 EAN、品牌、型号与规格搜索五个平台；上传的包装图会作为识别参考。可以在商品编辑中补充型号、辅助关键词和供应商商品链接。仍未识别时显示“待补资料”，已识别但未找到价格时显示“暂无报价”；平台访问受限与无结果分别记录，并保留实际检索词。不会把“未识别商品”当成真实名称写入。

## 工作流程

1. **数据调研**：添加仓库 SKU、中文名称或 EAN、成本和库存。上传实拍图。选中商品后批量调研，或在“查看分析”发起单品调研。调研覆盖 Amazon.it、TikTok Shop、AliExpress、Zooplus.it、Arcaplanet.it。结果包含来源、观察时间、同款/相似款/未核实状态、中文与意大利语简介；同款来源提供图片时补全封面。可手动补报价。未公开销量保持未知。
2. **选品排期**：勾选商品加入选品池，选择开始日期和每日数量（3、5 或自定义）。默认跳过周末，计入已排任务的容量。支持重排、取消与 CSV 导出。
3. **AI 创作工坊**：上传实拍图后发起任务。本地 Codex 使用当前 ChatGPT 登录，根据 `ecom-listing-prep` 技能制作两张严格九宫格、坐标切割、Real-ESRGAN x4、最终 18 张 1000×1000 图。全局风格与单次附加提示词可编辑；点击成品图可指定局部修改，保留原图。每个任务单独目录，失败有日志和重试。检查图片后确认“可用于上架”。
4. **上架清单**：图片制作完成的商品自动进入清单。导出 ZIP，内含三个平台各自的意大利语 Markdown 草稿和图片目录，另有通用原图和分配清单。自行上传平台后勾选完成，可撤回。
5. **经营分析**：手动输入或 CSV 导入真实销售合计及费用。支持平台/日期筛选、营收/销量/贡献利润/利润率、柱状图/折线图/品类饼图。导出老板报告 HTML，可用浏览器打印为 PDF。

## 接入的真实边界

- 已实现本地 Codex CLI 调用，不需要给本系统配置 OpenAI API Key。启动任务前检查 `codex login status` 为 ChatGPT。子进程移除 `OPENAI_API_KEY`；提示禁止回退付费图片 API。
- 2026-09-17 本机能力探测：CLI 会话暴露 `image_gen__imagegen`，**没有图片模型选择参数**。因此不能强制指定或宣称实际使用 **Image Gen 2.5**。工作台保留请求名称并明确提示版本未验证。
- 未接入三个商家平台的官方 API：需要用户各平台商家应用、授权和对应接口权限。当前自动调研由本地 Codex 浏览公开页面。不能将商家 API 等同于公开竞品销量接口。
- 搜索可能被登录墙、反爬、地域或搜索索引限制。无来源不造数据；同款与相似款分开。SKU 是内部标识，首录必须补商品名称/条码，之后可复用档案。
- 未拿到实际仓库商品参考图，本次没有对真实库存执行完整生图。内置工具可见与实际生成成功不同；以每次任务日志和 18 图验收为准。没有将能力探测标成生产验收。
- 平台图片分配为制作建议，不是官方审核保证。Amazon 主图候选使用纯白无文案图；TikTok 专用方图使用九宫格第 9 格的生活场景，竖版广告/短视频不属于本次自动生成；AliExpress 详情模块独立归类。上架前核对实际类目要求。
- Markdown 文案只使用已知产品事实，未知尺寸、重量、材质、EAN、认证保留“待核实”。不声称自动完成平台发布。

## 利润与预测口径

设置里的费率为初始假设，可编辑。进货和物流按不含可抵扣税金额填写。目标售价计算：

```
目标含税售价 = (进货成本 + 物流)
 / ((1 - 目标利润率 - 广告预留率 - 退货预留率)/(1 + VAT税率) - 平台费率)
```

平台费按含税售价计算；广告和退货预留按不含税收入计算。利润率以不含税收入为分母。

分析中的贡献利润 = 含税营业额 − 销项税 − 进货成本 − 平台费 − 物流 − 广告 − 退款/损失。贡献利润率以营收扣税扣退款为分母。未扣固定人工、仓租、所得税，不能作为最终净利润。

没有销售数据时不预测月销量。至少 14 个日历天、5 条记录后，以最后一条记录为基准、最近 30 天日均销量外推 30 天，标明低置信度；无订单日计零，缺报会低估。不是基于竞品评论数推算销量。

## 数据、备份与运行

- `data/petops.sqlite3`：商品、销售、排期、任务、设置。
- `data/references/`：原始商品图。
- `data/runs/<任务ID>/`：每个任务的事实、提示、日志、九宫格、裁剪图与交付。
- `data/integration-check/`：隔离的连接测试资料，不进入真实商品库。
- `连接与设置 → 导出完整备份`：导出 JSON 记录及素材。需要完整离线备份时，先停止服务器，再复制整个 `data` 目录；恢复时在停服状态还原该目录。
- `start.ps1` 隐藏启动服务器，日志在 `server.log` / `server-error.log`。已有本机服务时复用。
- 服务重启后，将上次未完成的任务标为“已中断”，用户可重试。避免重复生成费用，不自动重复执行。
