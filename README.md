# PetOps Studio · 作图与上架

当前版本：**2.0.0**。变更见 [CHANGELOG.md](CHANGELOG.md)。

意大利 B2C 宠物电商的本机工作台。2.0 起只做两件事：**作图**和**上架**。调研、排期、销售复盘改用 Excel，物流用 Packlink PRO。

## 整体流程（2 + 2 + 2）

| 环节 | 工具 |
|---|---|
| 选品调研 | 选品助手（第三方）→ `excel/选品调研对比表.xlsx` |
| 排期、上架状态、销售、复盘 | `excel/上新排期与销售统计表.xlsx` |
| 作图 + 图片管理 | 本系统 · 作图 / 画廊 |
| 上架 | 本系统 · 上架中心 |
| 物流 | Packlink PRO（第三方） |

## 启动

双击 **启动系统.cmd**，浏览器打开 `http://127.0.0.1:3310`。需要 Python 3.11+，首次执行 `python -m pip install -r requirements.txt`。服务只监听本机。

作图需要：Codex CLI（`codex login` 登录 ChatGPT）、九宫格电商法技能、Real-ESRGAN。路径可用环境变量 `PETOPS_CODEX`、`PETOPS_LISTING_SKILL`、`PETOPS_FINALIZER`、`PETOPS_REALESRGAN`、`PETOPS_AE_PUBLISH_SKILL` 指定。设置页显示每一项是否就绪。

## 三个页面

1. **作图**：按 AliExpress 官方素材规范（九宫格电商法 V2.0）生成一整套素材：
   - 主图 6 张（1:1，1000×1000），顺序：01 正面全景（首图，可印品牌和核心属性）→ 02 侧面 → 03 背面 → 04 细节 → 05 场景 → 06 尺寸
   - 营销图 2 张：1:1 白底无文字（1000×1000）+ 3:4 场景（900×1200）
   - 备用图 2 张：核心卖点、颜色/款式
   - 详情图 9 张（手机端模块）：整体展示、核心卖点、参数 & 规格、细节特写、场景使用、使用 & 安装指南、售后 & 服务提示、尺码指南、保养
   - 尺寸：商品资料里填“尺寸”或“尺码表”（多个尺码每行一个，英寸会自动换算成厘米），尺寸图、参数图和尺码指南都会标出具体数字；不填只画测量示意。
   - 颜色 / 尺寸（可选）：作图页第 3 步勾选“多颜色”“多尺寸”即可，AI 从实拍图（如供应商色块和尺寸表）识别。每个颜色一张白底 SKU 图（variants/），每个尺寸一张标好数字的尺寸图（sizes/）。前 5 张与 3:4 场景图合在第三张图里生成，超过 5 张自动加第四张九宫格，最多 14 张。
   - 同一商品的所有图片使用同一只宠物：可在商品资料里填“宠物模特”；留空时 AI 选定一只并自动记住，下次沿用。
   - 左侧队列可勾选多个商品批量作图（依次执行），进行中的任务可以取消。
2. **画廊**：所有商品一屏浏览，按“有图片 / 待作图 / 待上架 / 已上架”筛选。商品页有三个标签：
   - 图片：18 张成品 + 九宫格原图；点击放大，← → 切换，逐张下载；在大图里写一句话即可局部修改，结果与原图对比后再采用，可随时恢复原图。检查完勾选“可用于上架”。
   - 上架信息：三个平台的标题、卖点、描述、关键词、价格、状态和商品链接，一键复制。
   - 商品资料：事实字段、实拍图、任务记录。
3. **上架中心**：总表看每个商品在三个平台的状态。编辑页：
   - “AI 生成三平台文案”：Codex 根据资料和实拍图写意大利语标题 / 卖点 / 描述 / 后台关键词 / 商品属性，附中文对照和“上架前需核实”清单，不编造尺寸、材质、认证。
   - 字数计数按平台限制变色（AliExpress 标题 128、Amazon 标题 200 / 5 条卖点 / 关键词 250 字节、TikTok 标题 255），修改自动保存（Ctrl+S 立即保存）。
   - 右侧显示本平台该用哪些图、按什么顺序上传（Amazon 用 1:1 白底营销图做主图）。
   - 设置里的“售后 & 服务提示”是详情图 D7 唯一可用的服务话术，留空时只放中性提示。
   - **资料包**：`listing.json`（兼容 ecom-listing-prep / ecom-aliexpress-publish / ecom-json-to-upload-xlsx）+ 图片 + 三平台文案 Markdown。

**从排期表导入**：画廊右上角选择 `上新排期与销售统计表.xlsx`（或原来的 01_商品进价表），按 EAN 建档或更新，只写表格里有值的格子。商品 ID、电商原价、日常促销价和三个平台的上架状态也会带入。

## 自动上架：现状

| 平台 | 方式 | 状态 |
|---|---|---|
| AliExpress | Codex + Playwright MCP 操作已登录的卖家后台，按 `ecom-aliexpress-publish` 技能填写，**只保存草稿** | 已接入，实验性。需先配置 Playwright MCP（设置页有步骤）；尚未端到端跑通 |
| Amazon.it | 官方 SP-API Listings Items API（`putListingsItem`），图片以 URL 提交 | 可行。需专业卖家账号注册私有开发者应用、自授权，并准备图片公网地址 |
| TikTok Shop 意大利 | Partner Center Custom App + Product API | 可行。需申请商品权限并通过审核 |

AliExpress 自动存草稿的前提：图片已确认、标题描述齐全、售价与库存已填、技能与 Playwright MCP 就绪。程序从不输入密码、不处理验证码，遇到登录页会停下；欧盟责任人与制造商留给人工选择。

## 两个 Excel

格式照你的 01_商品进价表 / 02_销售统计表：一个标题行、一行黄色表头，每行一条记录，公式和你原来的写法一样（`=0.08*E+0.05*F`、`=E*20%`）。运行 `python tools/build_workbooks.py` 生成到 `excel/`，会自动带入 `F:\电商工作流` 里两个表的现有数据。`excel/` 含经营数据，不进 git。

- **选品调研对比表**（1 张表）：每行一个候选商品。填进货价、三个平台的售价和月销量（来自选品助手）、我方售价和预估月销量，自动算出税后进货价、三平台最低价、月销量合计、佣金、IVA、单件利润、利润率和预估月利润。结论列选“上新 / 观察 / 放弃”。
- **上新排期与销售统计表**（3 张表）：
  - 上新排期：就是进价表，多了计划上架日期、作图，以及 AliExpress / Amazon / TikTok 三列上架状态（选“完成”变绿）。
  - 销售统计：就是销售统计表，多了“平台”一列；总计在表头下面第一行。佣金按平台自动算：AliExpress 8%+5%，Amazon 15%，TikTok 9%（TikTok 为假设，按实际改）。
  - 月度复盘：每月、每个平台的订单数、销售额、利润和利润率，附柱状图。

## 数据

- `data/petops.sqlite3`：商品、上架信息、任务、设置。1.x 的商品记录会自动迁移（参考图、已上传状态保留）。
- `data/references/`：实拍图；`data/runs/<任务ID>/`：每个任务的请求、日志和产出；`data/listings/<SKU>/`：最近一次生成的资料包。
- 设置页“导出完整备份”。完整离线备份：停服后复制整个 `data` 目录。
- 服务重启时，未完成任务标为“已中断”，不会自动重跑（避免重复消耗额度）。
